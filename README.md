# Data-analyst-Task-3
Task 3: SQL for Data Analysis

Objective

To use SQL queries to extract, manipulate, and analyze data from a database.

Tools Used

- MySQL / SQLite
- SQL
- DB Browser for SQLite (optional)

Dataset

E-commerce SQL Database

Tasks Performed

1. Used SELECT statements to retrieve data.
2. Applied WHERE conditions to filter records.
3. Used ORDER BY to sort data.
4. Used GROUP BY to summarize data.
5. Performed INNER JOIN and LEFT JOIN operations.
6. Created subqueries to retrieve specific information.
7. Used aggregate functions like SUM(), AVG(), COUNT(), and MAX().
8. Created views for data analysis.
9. Used indexes to improve query performance.

Key Learnings

- Understanding database operations.
- Writing SQL queries for data analysis.
- Combining data from multiple tables.
- Analyzing data using aggregate functions.
- Improving query performance.

Deliverables

- SQL query file (.sql)
- Screenshots of SQL query outputs.

Outcome

Successfully learned how to manipulate, retrieve, and analyze structured data using SQL queries.

Conclusion

This task helped me improve my SQL skills and understand how SQL is used in real-world data analysis.
